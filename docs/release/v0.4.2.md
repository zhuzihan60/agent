# A4Diag v0.4.2

v0.4.2 closes the built-in controller-to-target production path. Linux GitHub
Actions validate the signed target protocol, socket-activated executor,
identity pinning, LOW apply/undo, HIGH approval, protected-resource denial,
replay protection, and the complete test suite.

The release contains separate controller and target archives. The controller
never installs a target automatically; an administrator reviews and installs
the target bundle on the intended host.
